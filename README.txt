CRE 324 — GROUP 10 WEBSITE PROJECT
Project: CampusConnect Student Academic Portal
Group: S/Nos 100–111

WHAT IS INCLUDED
- index.html: the website content and layout
- style.css: responsive design for phone, tablet and desktop
- app.js: mobile menu, course search, course details, connection status and install prompt
- manifest.json: Progressive Web App settings
- service-worker.js: caches core files so the site can work offline after an initial online visit
- icon.svg: application icon
- Project_Report.docx / Project_Report.pdf: report
- Defence_Questions_and_Answers.docx: oral defence practice

HOW TO OPEN
1. Extract the ZIP file.
2. For a quick preview, open index.html in a modern browser. Most visual features work this way.
3. For service-worker/offline and install features, serve the folder through localhost or deploy it to an HTTPS web host. Service workers generally do not run from a file:// URL.
4. For a simple local server, if Python is installed, open a terminal in this folder and run:
   python -m http.server 8000
   Then visit http://localhost:8000 in your browser.

IMPORTANT
This is a front-end demonstration. It does not include a real database, student authentication, a server, or live school records. All courses, timetable entries and announcements are sample data. Do not enter real passwords or sensitive student information. Your group should test it, personalise it, and understand the code before defending it.
